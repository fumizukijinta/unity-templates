# デザイン依頼のテンプレート
アセットの適用をお願いします。

【イメージ】
- 雰囲気: （例）ファンタジー寄りの明るいトーン / リアル系 / ローファイ
- 色味: （例）青系のクールな配色
- 参照: （あれば）この画像のような雰囲気 → 画像を貼る

【対象】
- 玉 / 床 / 壁 / 背景 / ゴール演出 の5役割

【手順】
1. Assets 配下の購入済みアセットを棚卸ししてカテゴリ別に一覧化
2. 各役割ごとに候補2〜3個＋選定理由を提示（適用はまだしない）
3. 私の承認後、候補を1つずつ適用して同じカメラ位置で capture_game_view
4. 比較画像を見せてください。私が選んだら全面適用してください

【制約】
- 物理挙動を壊さないこと: コライダーと Rigidbody 設定は置き換え後に必ず確認
- スケール: 適用後も迷路のセルサイズ・玉の直径が変わらないこと
